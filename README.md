# Notturno Experience

Mobile illustrated scroll journey by **fatihyaylacimk**.

11 scenes with Turkish and English narration, shared sound effects, scroll-driven camera movement and layered illustrations.

Use TR / EN to select a language, and enable sound using the sound button.

The site is a static 2.5D recreation using illustrated layers; it does not contain the original website’s rigged 3D characters. All runtime assets are included in this repository.

GitHub Pages publishes the main branch from the repository root. The .nojekyll file disables Jekyll processing.
